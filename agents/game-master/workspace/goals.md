# Goals

_The mission: kill the boredom by doing shit that matters. Set goals, break them
down, make them happen._

## Context
Girlfriend moved to the other side of the world (~Sep 2026). Owner feels a loss
of purpose. The mission is to build a new daily structure that's *his own* — the
goals below are the scaffolding for that. Boredom/YT-spiral is the symptom;
purpose and momentum are the cure.

## Active goals
<!-- goal | why it matters | next action | due -->

### 1. Body — MAINTAIN gym habit (already established)
Why: physical progress is the fastest way to feel purpose and beat low mood.
Status: already a regular. This is a keep, not a start. Just don't let it slip.

### THE REAL LEVER: the post-cook evening block
Pattern: gym → groceries → cook → "chill" → day's gone. "Chill" (mostly YT)
eats the one window where the side project + earlier sleep should live.
Fix: carve a protected ~45–60 min block after dinner for ONE deliberate thing
before any scrolling. Guard sleep with a hard lights-out time on the far end.

EVENING FRAME (locked):
- ~19:30 done eating
- 19:45–20:30 THE BLOCK — one deliberate thing, no YT first
- 20:30–22:15 chill (earned)
- 22:15 wind-down alarm — screens down
- 22:45 lights out
- wake early with something to get up for

Note: "feels too early to sleep" = revenge bedtime procrastination. Root cause
is the day having no block that felt like his own. The block cures the insomnia.

### 2. Money side project
Why: income + something to build = new purpose engine.
- Next action: brain-dump 3 project ideas (skills you have × things people pay
  for). We pick ONE next.

### 3. Sleep earlier
Why: earlier nights fix energy, mood, and free up mornings.
- Next action: set a target lights-out time + a "wind-down" alarm 30 min before.

### 4. Less YouTube / passive scroll
Why: it's eating the hours that could go to the above three.
- Next action: pick ONE lever — app timer, log-out, or a swap activity for the
  urge. Start with one.
